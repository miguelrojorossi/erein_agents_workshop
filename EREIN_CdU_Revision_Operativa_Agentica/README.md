# EREIN | PoC de revisión operativa

**Paquete de preparación para Google Cloud · Versión 1.0 · 15 de octubre de 2026**

## Empezar aquí

Leer `00_Documentacion/Guia_Implementacion_PoC.pdf`. Contiene objetivo, alcance, inventario, preparación, contratos y criterios de aceptación.

Este paquete aporta datos sintéticos y especificaciones para construir la PoC. El agente, las herramientas y el despliegue cloud se implementan en el entorno acordado.

## Organización y acceso

| Carpeta | Contenido | Acceso del agente |
|---|---|---|
| 00_Documentacion | Guía e índice de escenarios | No necesario |
| 01_Datos | CSV, esquemas y consultas SQL | Mediante herramientas por caso |

10 expedientes, 63 evidencias iniciales, 203 transacciones, 30 resúmenes mensuales, 24 referencias documentales iniciales y 13 reglas de ejemplo. Fecha simulada: **14/10/2026**. Periodo bancario: julio-septiembre de 2026.
